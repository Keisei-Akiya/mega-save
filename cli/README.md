# mega-save CLI

Single binary entrypoint. Site docs:

- [X / Twitter](docs/x.md)
- [pornavhd](docs/pornavhd.md)
- [SpankBang](docs/spankbang.md)
- [WNACG photo-slide → PDF](docs/wnacg.md)

```bash
cargo build -p mega-save --release
./target/release/mega-save x --help
./target/release/mega-save pornavhd --help
./target/release/mega-save spankbang --help
./target/release/mega-save wnacg --help
```
